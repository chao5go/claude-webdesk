# Roadmap

Shipped in 0.1: browser tasks and SSE, native session resume/fork, full history management, screenshot uploads, artifact downloads, cost/usage display, budget flags, isolated demo, capability doctor, local plugins, npm/Python distributions.

Priorities are proposals, not implemented features or delivery promises:

1. English UI with a language switch and translated dynamic states.
2. Indexed/paginated session search for large histories.
3. Explicit history retention and a trash restore UI.
4. Permission approval interaction using a supported Claude host protocol.
5. Workspace switching that keeps task, context and file roots coherent.
6. Queued tasks and per-project concurrency with clear process isolation.
7. Real CLI integration coverage across supported Claude versions and macOS.

## Helping the project reach the right users

The repository ships a real screenshot, runnable no-model demo, bilingual README, one-command installs and issue templates so a visitor can understand and try it quickly. Improve those before adding broad feature claims.

For launch, record the actual workflow: paste screenshot → run a task → reconnect → download a result. Share it only in communities where self-hosted Claude workflows are relevant, following their posting rules. Explain current limitations and ask for concrete feedback. No unsolicited promotion, fabricated benchmarks, purchased stars or automated outreach is part of this project.
