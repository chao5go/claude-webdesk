# Changelog

## 0.1.0

First Claude-specific release: live tasks, persisted history, native session resume/fork, screenshot/file uploads, artifact downloads, CLI-reported cost and token usage, budget control, full history search/export/trash/handoffs, local plugins, isolated demo and doctor. Based on the author's codex-webdesk architecture and Claude history viewer; file workflows inspired by remote-fileshare. No real paid-model end-to-end run is included in automated validation.
